# DSH Desktop 推理等级滑杆

一个面向 DSH Desktop Web Client 的非官方插件。滑杆读取当前模型公开的推理等级，并通过 DSH 会话模型选择接口提交所选等级；插件不自行构造 HTTP 请求，也不伪造模型能力。

本项目与 DeepSeek、OpenAI 或 Codex 无官方关联。

## 功能

- 显示当前模型可用的推理等级，并将选择提交给 DSH。
- 左上角闪电按钮提供独立的一次性子代理偏好：切换按钮后，下一条非空文字消息会附加一条可见提示；提示发送后即消费。它不是推理等级参数。

## 生效条件

- 当前模型必须在 DSH 模型目录中公布推理等级。没有等级时，滑杆会禁用并提示检查 DSH 模型设置。
- DSH Desktop 的 provider 适配器负责把所选等级映射到实际请求字段。官方 DeepSeek 模型使用其模型目录/路由能力；自定义 OpenAI 兼容模型可在「设置 > 模型」中为每个模型配置推理等级及对应的 API 参数值。
- 档位名称和 API 参数值不是一回事。只添加模型及服务商实际支持的档位，并按服务商文档填写参数值；不同 OpenAI 兼容服务可能采用不同字段或取值。

插件提交等级后，是否以及如何写入请求由 DSH 当前 provider 和模型配置决定。仅凭界面显示或回答风格变化，不能证明服务端应用了该参数。

## 安装

将本仓库克隆或下载到本机，然后在 DSH Desktop 插件管理器中选择安装本地 bundle/目录，并选择包含 `package.json` 的仓库根目录。插件没有额外的 npm 依赖或构建步骤。若安装管理器提示需要重启，按其提示操作。

## 配置与验证

1. 对官方 DeepSeek 模型，先使用 DSH 模型目录提供的等级；若目录没有等级，检查当前 DSH 模型设置是否能为该模型声明等级。
2. 对 OpenAI 兼容自定义模型，打开「设置 > 模型」，在对应模型的「推理等级」中添加服务商支持的等级，并填写该等级实际发送的 API 值。不要把某一家服务商的取值直接套用到另一家。
3. 回到会话，确认滑杆显示了该模型配置的档位；切换档位后，先确认 DSH 会话选择已更新，再用服务商请求日志或其他可见的请求记录核实实际参数。只看回答内容不足以验证参数是否生效。

本插件已在 DSH Desktop v2.0.18 / engine 0.2.1-rc.2 上完成本地加载和会话层检查。测试中，切换档位后 DSH 会话投影中的 `reasoningEffort` 随之更新。没有捕获服务商收到的原始 HTTP 请求体，因此这项检查不证明服务端实际收到了或应用了对应参数。

本地检查的 DSH 源码显示，模型设置可以提供 `reasoningEfforts` 等级到 API 参数值的映射；本插件只通过会话选择接口提交等级，不修改 DSH 安装目录或 provider 适配器。闪电按钮通过包装 DSH 会话发送方法，在下一条非空文字消息前追加一次提示；如果宿主后续更改这些方法，提示功能可能失效，但不会改变推理等级选择逻辑。

## 检查

运行 `npm run check` 检查插件入口和客户端脚本语法。该检查不安装插件，也不发送模型请求。
